存档与空间管理 / V17 / 2026-10-17

新任务默认“轻量存档”，生成按钮旁可切换“独立副本”。选择按项目在浏览器记忆，并在提交时写入 job.json；后台任务不受之后切换项目或选项影响。已有任务没有该字段时继续沿用原来的独立保存方式。

布局存档
布局只保存图层参数和素材 ID；素材快照单独固定。自动保存发现布局未变化时不重写 current.json，也不重复写操作日志。重复保存完全相同的布局会返回既有存档，界面显示已复用；真正变更仍产生新版本。不自动删除命名存档。

素材快照
通过 SHA256 在 projects/_shared/content-store/v1/blobs/ 保存不可变原始字节。项目素材索引、图层 ID 和现有布局格式不变。不同项目使用同一素材只固定一份；原素材被替换或移除后，存档仍可读取已经固定的旧内容。旧 originals/ 快照在实际使用时校验迁移到共享池，确认保存成功后才去掉该缓存重复项。用户提供的原始素材不与缓存共享可写文件。

生成结果
planes/、textures/、materials/、assets/、previews/ 是内部生成缓存。轻量任务完成后，相同图片及缓存 SVG 使用共享内容文件和硬链接，原路径不变；删除某个任务目录不会删除其他任务的同名内容。后端重试写入现有缓存前先分离共享文件，防止改动另一个版本。文件系统不支持硬链接时保留独立文件并记录回退。
surface-sources/ 源稿、原模型、用户工程文件和 export/ 最终 PNG 不参与硬链接去重，可继续独立编辑。内部生成缓存请作为不可变结果使用；手工修图使用 export/ 中的副本或另存文件。

下载压缩包
轻量任务目录不再额外保存一份完整 ZIP，而是保存 .archives/ 中的打包清单。点击原有下载链接时直接向浏览器流式输出 ZIP，服务端不产生常驻或临时完整压缩包；下载到本机的 ZIP 仍是正常文件。最终贴图包依旧扁平排列，数量、通道、文件名和原 UV 规则不变。直接在资源管理器找结果时，请使用 export/ 或界面下载入口。
独立副本模式继续生成实际 ZIP 文件。历史物理 ZIP 仍照常下载。打包依赖丢失会报告缺失文件，不静默输出不完整包。

模型预览
轻量模式把原有与新涂装的图像按原字节固定到共享池；新 .blend 使用相对外链并启用 Blender 压缩，不重复内嵌图像。模型几何、UV、材质参数与贴图像素不变，重新打开仍可使用。不要只移动一个轻量 .blend 到另一台电脑：需要独立搬运时生成“独立副本”，模型将内嵌图片。

追溯与恢复
每个轻量任务的 evidence/storage.json 记录文件摘要、共享位置、逻辑共享字节及本次消除的重复字节；前者不能当成实际节省空间。外链场景另有 evidence/scene-storage.json。路径仍可被现有映射和增量复用流程读取。
共享池属于工程数据，不能当临时缓存手动整体删除。当前不自动清理共享池或历史版本，以避免再次清理掉仍被引用的唯一资源。本次升级没有对历史生成目录做批量去重或删除；空间收益主要从新的生成任务开始累计。
