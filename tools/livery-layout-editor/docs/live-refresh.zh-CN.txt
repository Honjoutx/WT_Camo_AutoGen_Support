实时同步与通用流程 / 2026-10-18

默认展示
流程页展示通用设计方法。修复向导使用结构规则和通用坐标说明，修复记录默认收起。当前项目自己的名称、画布和图层仍正常显示，方便明确操作目标。
历史资料继续保留在工程文件中，不在默认流程页罗列，不自动作为其他项目的角色、配色、样式或待办要求。只有明确要求参考时才读取相关内容。

实时更新
画布上方“实时同步”默认开启，可随时暂停。工具约每秒检查一次轻量文件版本，确认后台文件稳定后重新读取；没有变化时不重建整个项目，也不重新扫描大文件内容。
后台布局、分区源稿、遮罩、参考图、素材和项目配置的变更会自动反映到界面。保留当前分区、选中图层以及相同画布尺寸下的缩放与平移。图片链接带版本号，避免浏览器一直显示旧图。
新增或修改项目列表会更新选择器，不擅自切换用户当前查看的项目。

本地修改保护
正在拖动、编辑属性、保存或加载时暂缓覆盖。保存携带所读版本，后台内容已变化时拒绝过时保存，保留浏览器中的手动修改。
出现冲突后可以“导出本地副本”，也可选择“备份并刷新”。后者先将本地布局参数保存到当前项目 state/recovery/，然后读取后台设计；不复制整套素材和贴图。
备份或加载期间又有新的手动修改时继续保留这些修改，不直接覆盖。后台文件尚未写完或连接中断时等待并重试。

工具界面更新
本机 CSS 改动会自动更新样式。前端脚本或页面结构变化后，在没有本地编辑、运行中的对话或聊天草稿时刷新页面，并恢复工程视图和已打开的对话面板。
有未保存布局或对话草稿时等待处理，界面会提示有更新。Python 服务代码的升级仍需要重启本机服务。

首次升级
已打开的旧页面先刷新一次以加载实时同步功能；之后后台设计变化无需反复整页刷新。
