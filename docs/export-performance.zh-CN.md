# 导出加速验证

2026-10-20，在 8 个可用逻辑 CPU、约 48 GB 内存、RTX 5070 Ti 的 Windows 主机上比较改动前实现和全速模式。使用已有完成任务的只读输入，输出与映射缓存另存测试目录，不覆盖工程。下列计时使用 CPU 计算路径。

| 阶段取样 | 改动前 | 全速模式 | 比率 |
|---|---:|---:|---:|
| 3 张原始图集、8 个域，18 张 4K PBR 输出：归并与 PNG 写盘 | 48.17 秒 | 13.63 秒 | 3.53× |
| 3 个主体 UV 域，18 张 2K 内部通道：映射、材质/法线计算与写盘 | 8.33 秒 | 3.66 秒 | 2.28× |

两组文件清单及解码后的每个像素完全一致。第二组双方分别重建映射缓存；未清空操作系统文件缓存。这是单机阶段取样，不代表完整工程固定提速倍数。第一组输出由约 30.5 MiB 增为 56.0 MiB：快速无损压缩以文件体积换取计算时间。

另以本机 CUDA 实测法线合成和平滑：测试样本 CPU/GPU 像素一致，三个并发域安全共享设备后端；没有把 GPU 初始化或首次内核编译时间隐藏为加速收益。

85 项自动测试通过，覆盖调度内存预算、输出顺序、16 位 PNG/NPZ 无损、平面材质合成、重叠面的覆盖顺序、受保护 UV、按文件剪枝、同名图集消歧、共用法线与 PBR 仅材质变化的归属。独立应用的隐藏窗口、语言保持、后台导出、ZIP 下载、Blender MCP 和本机 Codex 连接也通过验证。

使用方法与资源约束见 [README](../README.md#导出性能)。任务证据保存在 `evidence/export-performance.json` 和 `evidence/export-acceleration.json`，不随游戏贴图 ZIP 导出。
